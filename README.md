# GameAtOne

GameAtOne is a browser-based collection of casual games built by Abdul Hannan. Play with friends online or add bots in supported games.

## Games

- **UNO** — 2 to 6 players
- **Ludo** — 2 to 4 players
- **Checkers** — 2 players
- **Snakes and Ladders** — 2 to 4 players

Tic Tac Toe, Connect Four, Memory Match, Chess, and Hangman are shown as coming soon.

## Play

Open `index.html` in a modern browser, or serve the project with any static web server and open the served page. Select a game, create a room, then share the room code with friends. Other players can join using that code. Hosts can add bots in supported games.

Online multiplayer uses PeerJS for peer-to-peer connections and requires an internet connection. The page also loads PeerJS and Google Fonts from their respective CDNs.

## Project structure

- `index.html` — page markup
- `styles.css` — app styles
- `app.js` — game logic
- `favicon.svg` — browser tab icon
- `LICENSE` — MIT License

There is no build step or package installation required.
